# LPB Testing

Full instructions: nala/tools/landing-page-builder/README.md

## Session Setup

Log into DA first so Playwright can reuse the saved session:

```bash
npm run nala:login
```

## Tests

Run LPB smoke tests:

- **LPB_REF=local** opens da.live with `?ref=local`, pointing DA to your local `aem up` page.

```bash
LPB_REF=local npm run nala main @lpb # Run all 50+ tests
LPB_REF=local npm run nala main @lpb-e2e # Run all e2e tests
LPB_REF=local npm run nala main @lpb-non-e2e # Run all non-e2e tests
LPB_REF=local npm run nala main "@lpb-non-e2e @smoke" # Run non-e2e smoke tests
```

Run one LPB test in UI mode:

```bash
LPB_REF=local npm run nala main @lpb mode=debug # All tests with Debug UI
LPB_REF=local npm run nala main "@lpb-e2e-gated-guide" mode=ui # Individual test in UI mode
LPB_REF=local npm run nala main "@lpb-e2e-video-demo" mode=debug
LPB_REF=local npx playwright test nala/tools/landing-page-builder/landing-page-builder-e2e.test.js --project=da-bacom-live-chromium --workers=1 --headed
```

## Cleanup

This will clean up any pages generated by the LPB tests.

Dry run first:

```bash
node nala/tools/landing-page-builder/cleanup-generated-pages.js
```

Delete for real:

```bash
node nala/tools/landing-page-builder/cleanup-generated-pages.js --execute
```
